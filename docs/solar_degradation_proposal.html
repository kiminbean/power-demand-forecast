LID 광유도 열화와 연간 0.6% 노후화 곡선을 반영한 과학적 발전량 예측으로 SMP 입찰 정확도와 자산 가치 평가를 동시에 개선합니다.

EXECUTIVE SUMMARY

왜 노후화 모델이 필요한가

태양광 패널은 설치 첫 해 LID(Light Induced Degradation)로 약 3% 효율이 감소하고, 이후 매년 0.6%씩 추가 감소합니다. 이 노후화를 반영하지 않은 발전량 예측은 실제 발전량 대비 평균 8~15% 과대 추정되며, 사업성 분석과 SMP 입찰에 직접적인 손실을 초래합니다.

①

예측 정확도 향상

설치 연도별 노후화 곡선을 반영하여 발전량 예측 MAPE를 15% → 7% 이하로 개선

②

SMP 입찰 최적화

실제 효율 기반 발전량 예측으로 입찰 미달성 페널티 회피 및 수익 극대화

③

자산 가치 평가

노후 발전소의 잔존 가치 산정과 리파워링 의사결정을 위한 정량적 근거 제공

④

O&M 비용 절감

효율 저하 패턴 모니터링으로 비정상 노후화 조기 감지 및 점검 우선순위 결정

PROBLEM

MODEL

물리 정보 기반 노후화 모델

NREL, IEC 61215 표준과 국내 태양광 발전소 실측 데이터를 근거로 한 2단계 노후화(LID + 연간 감쇠) 수식

η(t) = max(0.80, 1 − D(t) / 100)
D(t) = 3 (t ≤ 1)
D(t) = 3 + (t − 1) × 0.6 (t > 1)
η = 효율, t = 설치 후 경과 연수, D = 누적 감쇠율(%)

실측 검증 가능한 단순한 수식

// web-v7/src/utils/powerPlantUtils.ts (line 49) export function calculateEfficiency(installDate: string): number { const totalYears = yearDiff + (monthDiff / 12); if (totalYears <= 0) return 1.0; // 1년차: 3% LID 감소 / 2년차+: 매년 0.6% 감소 const degradation = totalYears <= 1 ? totalYears * 3 : 3 + (totalYears - 1) * 0.6; // 최저 효율 80% (제조사 20년 보증) return Math.max(0.8, (100 - degradation) / 100); }

발전량 예측 통합 수식

노후화 효율을 BiLSTM 기반 SMP 예측 모델의 핵심 피처로 통합

E_daily = C × PSH × η(t) × W × D
E = 일일 발전량(kWh), C = 정격 용량(kW), PSH = 일조 시간(시간),
η(t) = 노후화 효율, W = 기상 보정 계수, D = 방위각 보정 계수
PSH

계절별 일조 시간

제주 기준: 봄·가을 4.0h, 여름 3.5h, 겨울 3.0h (KMA 단기예보 API 연동)

η(t)

노후화 효율

설치일 기반 동적 계산 (LID 3% + 연간 0.6%, 최저 80% 보장)

W

기상 보정 계수

맑음 1.0, 부분 구름 0.7, 흐림 0.4, 비 0.15 (실시간 KMA 데이터 연동)

D

방위각 보정

남향 1.0, 동·서향 0.85, 평지 0.92 (NREL 실측 기준)
