04

모델 — 예측은 어떻게 만들어지나

수집한 CSV를 모델이 읽을 수 있는 형태로 가공(피처 엔지니어링)하고, 시간 순서를 지켜 학습/검증을 나눈 뒤, 딥러닝 모델(LSTM 계열)을 학습시킵니다. 학습은 이 맥북의 Apple MPS(Apple Silicon 전용 GPU 가속)에서 수행했습니다 — CUDA(GPU 서버) 없이 로컬에서 학습 가능했다는 점이 이 프로젝트의 환경적 특징입니다. 다만 2026-11-06부터 API 기본 수요 모델은 LSTM이 아니라 AR+GBM입니다 — 시간대별 선형 자기회귀(AR) 예측의 오차를 그래디언트 부스팅(GBM)으로 보정하는 모델로, CPU에서 학습하며 2025년 실측 비교에서 LSTM보다 정확했습니다. 근거: models/demand_ar_gbm/metadata.json · docs/2026-11-06-demand-retrain-raw-target.md 12절.

MAPE가 낮을수록 좋습니다. 지금 API 기본 수요 모델(AR+GBM)은 2025년 평균 오차 4.67%로, 직전 1시간 값을 그대로 쓰는 기준선(6.16%)보다 정확합니다. 같은 모델도 평가 기간이 다르면 수치가 달라지므로 같은 기간끼리만 비교해야 합니다 — 같은 LSTM이 2023-07~2024-12에는 4.16%, 예측이 더 어려웠던 2025년에는 5.22%입니다. 예전 이 표의 6.06%는 2025-12 학습 리포트의 값(시험 구간 2023-07~2024-12)인데, 그 체크포인트를 같은 기간에 API와 같은 경로로 다시 채점하면 9.78%로 재현되지 않았고 기준선(5.28%)보다도 나빠, 2026-11-05에 다시 학습한 모델로 교체했습니다. 근거: docs/benchmark-2026-11-06/rescore_old_lstm_out.json

R²는 1에 가까울수록 좋고 0 이하는 "추측만 못함"을 뜻합니다 — v3.4는 이 기준으로 사용을 보류했습니다. SMP(가격) 예측이 수요 예측보다 어려운 것은 가격이 수급 상황에 즉각 반응하기 때문이며, 이를 인지하고 walk-forward(롤링 기간 재검증) 방식을 도입했습니다. 그 검증에서 제주 가격으로 다시 학습한 v4.1이 "전날 같은 시간 가격"보다 나빠, 지금 SMP 예측 화면은 이 기준선 값을 보여 줍니다. 화면에 나오는 "검증 MAPE"(2026-11-06 12.45%)는 같은 기준선을 최근 날들로 다시 잰 값이라 표의 11.75%와 조금 다릅니다.

06

용어 사전 (비도메인 독자용)

SMP (계통한계가격)
전력 도매시장에서 1kWh당 매시 결정되는 거래 가격. 수요가 공급능력에 근접하면 급등한다.
공급예비율
(공급능력 − 수요) ÷ 수요. 낮으면 정전 위험이 커지는 안전 여유 지표.
EPSIS / KPX
한국전력거래소(KPX)와 그 전력 통계 시스템(EPSIS). 전력 시장 데이터의 공식 원천.
ASOS
기상청 종관기상관측(ASOS) — 기온·습도·풍속 등을 정시 관측하는 공식 기상 관측망.
THI (불쾌지수)
기온과 습도를 조합한 지수. 여름 에어컨 사용→전력수요와 강한 상관.
LSTM
시간 흐름이 있는 데이터를 다루는 딥러닝 신경망. "최근 168시간 → 다음 시간" 식의 패턴 학습에 사용.
시간대별 선형 AR (자기회귀)
수요의 과거 값으로 다음 1시간 수요를 계산하는 단순 선형식. 하루 24개 시간대마다 따로 맞추고, 1·2·24·25·48·168·169시간 전 수요와 요일만 쓴다. 근거: src/models/hourly_ar.py:5-6
GBM (그래디언트 부스팅)
작은 결정 트리를 차례로 쌓아 앞 트리가 틀린 만큼을 다음 트리가 고치는 기계학습 모델. 여기서는 scikit-learn HistGradientBoostingRegressor가 시간대별 AR이 틀린 양(잔차)을 예측해 더하며, 이 AR + GBM 조합이 지금 서비스의 기본 수요 모델. 근거: src/models/ar_gbm.py:5 · api/config.py:47
MAPE / R²
예측 정확도 지표. MAPE는 평균 오차(%), 낮을수록 좋음. R²는 설명력, 1에 가까울수록 좋음(0이면 평가 기간의 평균값만 찍은 것과 같고, 음수면 그보다 못함).
누수 (data leakage)
검증에 쓸 정보가 학습에 새어 들어가 성능이 실제보다 과대평가되는 결함. 시계열은 시간 순서로 나누고, 스케일링 기준값·이상값 상한도 학습 구간에서만 구해야 막을 수 있음.
walk-forward 검증
기간을 한 칸씩 옮겨가며 반복 검증하는 방식. 시계열 모델의 실전 성능을 더 신뢰도 있게 측정.
MPS
Apple Silicon의 GPU 가속 인터페이스. 이 프로젝트의 LSTM은 CUDA 대신 MPS로 로컬 학습. 지금 서비스가 기본으로 쓰는 수요 모델(AR+GBM)은 GPU 없이 CPU로 학습. 근거: models/production/training_report.json:3 · src/models/ar_gbm.py:27
Tailscale Funnel
내 기기에서 지정한 웹 서비스만 공인 HTTPS 주소로 공개해주는 터널링 서비스(기기 전체가 열리지는 않음). 이 모든 웹페이지가 별도 서버 없이 맥북에서 서빙되는 이유.
